Giga brings company work, connected tools, and durable context into one AI workspace. The building blocks below help you decide **where work belongs**, **what Giga can access**, and **how repeatable work gets reused**.

## Core concepts

### Users, Groups and sharing

Everything in Giga is built on one simple model for who can see and use what.

```mermaid
graph TB
    A["Anything in Giga<br/>Integrations, Skills, Context Cards, etc."]
    A -->|share with a person| U[User]
    A -->|share with a Group| G[Group]
```

- **Users.** Everyone on your team has their own Giga account. What you create starts out private to you.
- **Groups.** A Group is a set of people, such as a team, a department, a project, or the whole company. You add users to Groups.
- **Sharing.** Almost anything in Giga can be shared with a whole Group or with one specific person.

The same model applies everywhere, in Giga Web, Slack, ChatGPT, and Claude, and Giga only ever draws on the things each person has been given access to.

### Tracks

A **Track** is a project: one ongoing piece of work, like _Acme renewal_, _Q4 hiring plan_, or _Website redesign_.

It's the place where everything about that work comes together:

- **Chats** about the work, so conversations aren't scattered
- **Memory** of what's been decided, learned and done along the way
- **Context** such as background notes, links and reference material

When you work in a Track, Giga automatically brings in that Track's memory and context, and what you learn gets saved back to it. The next person to pick up the work starts from where things left off, not from scratch.

**Groups decide who. Tracks decide what.**

|              | Group                      | Track                          |
| ------------ | -------------------------- | ------------------------------ |
| **Answers**  | Who has access?            | What is this work about?       |
| **Contains** | People                     | Chats, memory and context      |
| **Lasts**    | As long as the team exists | As long as the work is ongoing |
| **Example**  | Sales team                 | Acme renewal                   |

The two work together: a Track is shared with a Group, so the right people can see and contribute to it. One Group can have many Tracks. For example, the Sales Group might have a Track for each major deal.
