Most teams sign up for a long list of tools: one for AI models, one for data, one for scraping, one for every specialist job. Each one means another subscription, another account and another API key to manage.

**Giga Gateway** lets you skip that. Instead of subscribing to each tool yourself, your agents use it through Giga. In the app, these are called **Instant tools**, and you'll find them in **Integrations → Instant**.

<Callout kind="info">Instant tools are in beta. You can browse the tools and set them up for your workspace now. Agents start calling them on Giga's account as Instant rolls out to your workspace.</Callout>

## How Instant tools work

<Steps>
  <Step title="Turn it on" icon="toggle-right">
    A workspace admin turns on Instant tools. Every tool is then available to your team, and admins can switch any of them off.
  </Step>
  <Step title="Ask your agent" icon="message-square">
    No accounts, no API keys. Just say "use DataForSEO to…" or "pull this with Semrush" and the agent calls it for you.
  </Step>
  <Step title="Pay from credits" icon="coins">
    Each call is paid from your workspace credits at the price shown on the tool: per call for data tools, per million tokens for models. Spending shows in **Activity & usage**.
  </Step>
</Steps>

## Managing Instant tools (admins)

Workspace owners and admins manage Instant tools in **Integrations → Instant → Manage**. Everyone else can see what's turned on.

- **Workspace switch:** turn Instant tools on or off for the whole workspace.
- **Per tool:** switch off any tool your team shouldn't use.
- **Monthly limit:** cap what a tool can spend each month.
- **Agent instructions:** tell the agent when to use a tool, for example "only use for keyword research" or "prefer this over web search".

When credits run out, Instant calls stop. The agent tells you and links to top up. Tools using your own keys keep working.

## Models

Giga runs on its own models out of the box. Every workspace has the **Giga managed** provider, which is always available and can't be removed.

To use your own account with a model provider, add its key in **Vault → Model Providers**, or from **Integrations → Models**. Keys are stored encrypted in the [Vault](/connect/vault), like every other credential.

## Why it matters

- **Fewer subscriptions:** stop paying for tools your team only uses occasionally.
- **Less admin:** no new accounts or keys to set up for every tool.
- **One place:** every tool your team uses through Giga is managed in the same place as your [connections](/connect/index).

## Frequently asked questions

<ExpandableGroup>
  <Expandable title="What if I already have my own key?">
    Your key wins. If someone on the team has connected the tool with their own key, the agent uses that, and Giga doesn't charge for it.
  </Expandable>
  <Expandable title="What does it cost?">
    Each tool shows its price: per call for data tools, per million tokens for models. Calls are deducted from your workspace credits.
  </Expandable>
  <Expandable title="Can I limit spending?">
    Yes. Admins can set a monthly limit on any tool and switch off any tool the team shouldn't use.
  </Expandable>
  <Expandable title="Who can change these settings?">
    Workspace owners and admins. Everyone else can see what's turned on.
  </Expandable>
</ExpandableGroup>
