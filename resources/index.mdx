## The core Giga model

Giga is organized around a small set of primitives.

| Primitive | What it is for |
| --- | --- |
| [Chat](/chats/index) | Direct work with Giga |
| [Group](/groups/index) | Placement and permission scope |
| [Track](/tracks/index) | Ongoing work with continuity |
| [Context Note](/tracks/context-notes) | Durable standing Track background |
| [Agent](/agents/index) | Named reusable AI role |
| [Skill](/skills/index) | Reusable task method or instructions |
| [Workflow](/workflows/index) | Reusable ordered process |
| [Pulse](/pulses/index) | Recurring scheduled work |
| [Connection](/connections/index) | Permissioned access to an external system |

These primitives can be combined around the way your team actually works.

## Company Brain underneath the work

Giga’s **Company Brain** is the permission-aware company context layer available to the current task.

Depending on relevance and access, it can draw from:

- workspace and Group guidance
- Tracks
- Context Notes
- Observations
- Current Track State
- files
- Connections and live external data
- Agents
- Skills
- Workflows
- user-level context

The live workspace remains the source of truth for what a user or Agent can actually access.

## Use Giga across different surfaces

Giga can be used from:

- [Giga Web](/use-giga-anywhere/web)
- [Slack](/use-giga-anywhere/slack)
- [ChatGPT](/use-giga-anywhere/chatgpt)
- [Claude](/use-giga-anywhere/claude)
- [Microsoft Teams](/use-giga-anywhere/microsoft-teams)

The same core Giga model and permission boundaries stay underneath, while file handling, rich UI, and exact tool availability can differ by surface.

## Product behavior stays live

Some parts of Giga are dynamic by design.

Current workspace membership, Connections, model availability, provider capabilities, permissions, schedule slots, and surface-specific features should be resolved from the live product rather than treated as fixed documentation facts.

> **Use the docs for the product model. Use the live workspace for the current state.**
