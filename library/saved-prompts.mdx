A **Saved Prompt** is a prompt you reuse. Instead of retyping it, start a chat from it.

Find them in **Library → Saved Prompts**. You can also link a Saved Prompt to Tracks from its page, so it's at hand for that work.

## Saved Prompt or Skill?

A Saved Prompt is a request you run, like a shortcut for something you ask often. A [Skill](/skills/index) is a method Giga follows whenever that kind of work comes up, without anyone asking for it by name.
