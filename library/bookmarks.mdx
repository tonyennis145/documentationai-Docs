title: References
description: Links and notes saved to your Tracks, all in one list.
---

A **Reference** is a link or note saved to a [Track](/tracks/index): a spec, a dashboard, a customer's site, a shared doc. **Cloud → Shared Resources → References** shows every reference from the Tracks you can access in one list. They're the same references as each Track's **References** tab.

## Who sees a Reference

A reference is visible to the people on its Track. A **private** reference is only visible to you.

## Saving a Reference

Add a link from a Track's **References** tab, or ask Giga to save one ("save this as a reference for the Acme Track").
