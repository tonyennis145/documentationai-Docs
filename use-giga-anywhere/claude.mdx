Use **Giga from Claude** when you want Claude's interface with Giga's company context and connected systems underneath.

Giga is not yet listed in Claude's Connector Directory, so the current setup uses a **custom connector** backed by Giga's remote MCP server.

## Connect Giga to Claude

### Individual Claude accounts

<Steps>
  <Step title="Open Connectors" icon="settings">
    In Claude, go to **Customize → Connectors**.
  </Step>
  <Step title="Add a custom connector" icon="plus">
    Select **+ → Add custom connector**.

    Name the connector **Giga**.
  </Step>
  <Step title="Add Giga's MCP endpoint" icon="link">
    Enter:

    ```
    https://app.getgiga.com/mcp
    ```

    Giga uses its normal OAuth flow, so you do not need to enter a separate Client ID or Client Secret.
  </Step>
  <Step title="Add and authenticate" icon="shield-check">
    Select **Add**.

    Claude will open Giga's normal OAuth flow. Sign in to Giga if prompted and approve access so the connector can act with your Giga permissions.
  </Step>
  <Step title="Enable Giga in a Chat" icon="message-circle">
    In a Claude Chat, select the **+** button, open **Connectors**, and enable **Giga** for the conversation.
  </Step>
</Steps>

### Team and Enterprise workspaces

On Claude Team and Enterprise, an **Owner or Primary Owner** first adds Giga for the organization:

<Steps>
  <Step title="Open organization connectors" icon="settings">
    Go to **Organization settings → Connectors**.
  </Step>
  <Step title="Add Giga" icon="plus">
    Select **Add**, hover over **Custom**, then choose **Web**.
  </Step>
  <Step title="Enter the Giga endpoint" icon="link">
    Add `https://app.getgiga.com/mcp` and complete Giga's OAuth flow when prompted.
  </Step>
  <Step title="Let members connect" icon="users">
    Each member then goes to **Customize → Connectors**, finds **Giga**, and selects **Connect** to authenticate individually.
  </Step>
</Steps>

## What carries through from Giga

Claude remains the interface. Giga continues to resolve the current user's permitted company context and capabilities.

Depending on the task and permissions, that can include:

- [Groups](/groups/index)
- [Tracks](/tracks/index) and Track memory
- [Connections](/connections/index)
- [Agents](/agents/index)
- [Skills](/skills/index)
- files and other permitted company context

Giga's Company Brain remains permission-aware, so connecting Giga to Claude does not give a user access to company resources they could not otherwise use.

## Using Giga in Claude

Enable Giga when the request needs company context, live connected data, or an action through Giga.

For example:

- "Use Giga to summarize what changed on the Atlas Track this week."
- "Use Giga to check the CRM and prepare me for this account."
- "Use Giga to find the latest relevant company context for this decision."

A Chat can link to at most one [Track](/tracks/index), and the Track should be explicitly selected or confirmed.

## Availability

Anthropic currently supports custom remote MCP connectors on Claude Free, Pro, Max, Team, and Enterprise. Free accounts are limited to one custom connector, and Team/Enterprise organizations require an Owner to add the connector first.

For current Claude requirements, see [Anthropic's custom connector guide](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp).
