Use **Giga from ChatGPT** when you want to work in ChatGPT while keeping Giga's permission-aware company context and connected tools underneath.

Giga is not yet listed in ChatGPT's public app directory, so the current setup uses a **custom MCP app**.

> **Before you start**
>
> ChatGPT controls who can create and use custom MCP apps. Full MCP support, including write actions, is currently available on ChatGPT Business and Enterprise/Edu on the web. Pro users can connect MCPs with read/fetch permissions in Developer Mode. If you do not see the settings below, your plan or workspace permissions may not support custom MCP apps yet.

## Connect Giga to ChatGPT

<Steps>
  <Step title="Enable Developer Mode" icon="settings">
    In ChatGPT, open **Settings → Apps → Advanced Settings** and turn on **Developer Mode** if it is available to your account.

    Workspace admins can also start from **Workspace settings → Apps → Create**.
  </Step>
  <Step title="Create a custom app" icon="plus">
    Open **Settings → Apps → Create** or **Workspace settings → Apps → Create**, depending on your workspace role.

    Name the app **Giga**.
  </Step>
  <Step title="Add Giga's MCP endpoint" icon="link">
    Enter the Giga remote MCP endpoint:

    ```
    https://app.getgiga.com/mcp
    ```

    Use **OAuth** for authentication.
  </Step>
  <Step title="Scan Giga's tools" icon="search">
    Select **Scan Tools** and wait for ChatGPT to discover the tools exposed by Giga.

    ChatGPT will open Giga's normal OAuth flow. Sign in to Giga if prompted, approve access, then return to ChatGPT.
  </Step>
  <Step title="Create and use Giga" icon="check-circle">
    Select **Create** when the scan finishes.

    Start a new Chat, open the tools/apps menu, and select **Giga** when you want ChatGPT to use current company context or take an action through Giga.
  </Step>
</Steps>

## What carries through from Giga

Connecting Giga to ChatGPT changes the interface around the work. Giga still resolves the current user's permitted workspace context and capabilities.

Depending on the task and current permissions, that can include:

- [Groups](/groups/index)
- [Tracks](/tracks/index) and Track memory
- [Connections](/connections/index)
- [Agents](/agents/index)
- [Skills](/skills/index)
- files and other permitted company context

Giga's Company Brain remains permission-aware. Using Giga from ChatGPT does not widen access to company information or Connections.

## Using Giga in a Chat

When a request needs fresh company data or an action through Giga, select or mention Giga for that message.

For example:

- "Use Giga to catch me up on the Acme rollout."
- "Use Giga to find the latest account context before my renewal call."
- "Use Giga to check the connected CRM and summarize what changed."

A Chat can link to at most one [Track](/tracks/index), and the Track should be explicitly selected or confirmed.
