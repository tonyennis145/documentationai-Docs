## One company layer underneath

Across supported surfaces, Giga keeps the same core product model:

- [Groups](/groups/index) for placement and access
- [Tracks](/tracks/index) for ongoing work and memory
- [Agents](/agents/index) for reusable AI roles
- [Skills](/skills/index) for reusable methods
- [Connections](/connections/index) for live external systems
- permission-aware Company Brain context

The interface can present those capabilities differently, and exact file or action support can vary by surface.

## Pick the surface, keep the context

Changing interfaces does not create a separate copy of your company context.

Giga continues to resolve current workspace state and the requesting user's permissions when the work runs.
