Use **Giga in Slack** when the work is already happening with your team there.

Slack uses Giga's normal integration flow, so setup is much simpler than the custom MCP setup required for ChatGPT and Claude.

## Connect Giga to Slack

<Steps>
  <Step title="Open your workspace menu" icon="menu">
    In Giga, open the workspace/profile menu in the lower-left corner.
  </Step>
  <Step title="Choose Use Giga in…" icon="plug">
    Select **Use Giga in…**, then choose **Slack**.
  </Step>
  <Step title="Authorize Slack" icon="shield-check">
    Follow the Slack authorization flow. If Slack asks you to choose a workspace, select the workspace where you want to use Giga.
  </Step>
  <Step title="Return to Slack" icon="check-circle">
    Once authorization finishes, return to Slack and use Giga from the Slack experience enabled for your workspace.
  </Step>
</Steps>

## The same Giga context still applies

Slack is another surface for Giga. The underlying company context and access rules still come from the live Giga workspace.

Depending on the request and current permissions, Giga can use relevant:

- [Groups](/groups/index)
- [Tracks](/tracks/index)
- Context Notes and Track memory
- [Connections](/connections/index)
- [Skills](/skills/index)
- files
- current user and workspace permissions

> **Permissions carry through**
>
> Using Giga from Slack does not give someone access to a Giga resource they could not otherwise use.

## Slack channels and Groups

A Slack channel can be linked to a Giga [Group](/groups/index) when that relationship has been configured.

Giga uses the live channel-to-Group relationship when one exists rather than guessing which Group a Slack discussion belongs to.

## Tracks still require explicit selection

A [Chat](/chats/index) can link to at most one Track.

Giga should not silently attach a Track based on a Slack channel or message topic. The Track should be explicitly selected or confirmed because Track attachment affects where observations from the Chat can become retrievable.

## Files and Slack actions

When the current Slack integration supports it, Giga can return generated files directly in Slack and use supported Slack actions such as searching messages, replying in a thread, or posting a message.

Consequential outward-facing actions still follow Giga's normal confirmation rules.
