---
title: Create Your First Giga Project
description: Start your first docs project in Giga.
---

## Steps
<Steps>
  <Step title="Go to Projects">
    Log in at `https://giga.com` and click "Projects" in the dashboard.
  </Step>
  <Step title="Create New">
    Click "New Project", give it a name and description.
  </Step>
  <Step title="Invite Team">
    Add team members' emails for collaboration.
  </Step>
  <Step title="Start Adding Docs">
    Use the Add Docs button to create your first documentation page.
  </Step>
</Steps>
