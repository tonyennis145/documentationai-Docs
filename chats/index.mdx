A **Chat** is where you work with Giga directly. You can ask questions, work through a task, create work product, or ask Giga to take action using the tools and context available to you.

What Giga can do in a Chat depends on the **live workspace state**: your permissions, the selected [Track](/tracks/index), available [Connections](/connections/index), and the tools exposed in that session.

## The interface can change

The Chat experience can vary by surface. Giga can be used through [Giga Web](/use-giga-anywhere/web), [Slack](/use-giga-anywhere/slack), [ChatGPT](/use-giga-anywhere/chatgpt), [Claude](/use-giga-anywhere/claude), and [Microsoft Teams](/use-giga-anywhere/microsoft-teams). Each surface can present the experience differently while the underlying workspace context and permissions continue to apply.

> **Surface-specific experience**
>
> The same request can look different across interfaces because each surface has its own display and file-handling rules.
