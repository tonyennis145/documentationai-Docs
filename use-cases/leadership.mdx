Leadership work often spans several teams, systems, and time horizons.

Giga can help bring the relevant context together while keeping access permission-aware and organizing ongoing work so important decisions and changes do not get buried across separate Chats.

## Keep strategic work in Tracks

Use a [Track](/tracks/index) for priorities that evolve over time.

Examples include:

- annual planning
- a major company initiative
- fundraising
- a strategic partnership
- a new market evaluation
- an executive hiring process

A Track keeps the durable background, memory, Current Track State, files, and linked Chats around one body of work.

<Columns cols="2">
  <Card title="Context Notes" href="/tracks/context-notes" icon="file-text" horizontal="false">
    Keep durable goals, constraints, definitions, and standing context.
  </Card>

  <Card title="Current Track State" href="/tracks/memory" icon="activity" horizontal="false">

  </Card>
</Columns>

## Prepare for recurring reviews

Leadership teams often revisit the same questions on a regular cadence.

A [Pulse](/pulses/index) can schedule recurring work such as:

- review the latest changes around a priority
- prepare a weekly operating summary
- surface unresolved decisions
- check an ongoing Track for meaningful developments
- prepare context before a recurring leadership review

The schedule controls when the work runs. An Agent or Track can provide the recurring context when appropriate.

## Pull context across approved systems

Leadership questions often require information from several parts of the business.

[Connections](/connections/index) let Giga work with live external systems when the current permissions allow it.

For example, a leader might ask Giga to prepare a company update using relevant information from connected systems alongside Track context and company guidance.

The exact systems and actions depend on what is connected in the current workspace.

> **Live data stays permission-aware**
>
> Giga uses the Connections and provider permissions available to the current user or Agent. Access stays scoped even when the question spans several teams.

## Research a decision

A [Chat](/chats/index) can be useful for one-off strategic research.

For work that continues across several sessions, attach the Chat to an explicitly selected Track so the research can stay connected to the broader decision context.

A leadership research pattern might look like:

<Steps>
  <Step title="Frame the question" icon="target" title-type="p">
    Define what needs to be understood and which constraints matter.
  </Step>

  <Step title="Gather evidence" icon="search" title-type="p">
    Use approved company context, Connections, and external research capabilities available in the current surface.
  </Step>

  <Step title="Separate facts from open questions" icon="filter" title-type="p">
    Keep confirmed evidence distinct from uncertainty and assumptions.
  </Step>

  <Step title="Preserve the durable result" icon="folder" title-type="p">
    Keep meaningful decisions, changes, and work product with the relevant Track.
  </Step>
</Steps>

## Use Agents for recurring leadership roles

An [Agent](/agents/index) can help when leadership work benefits from a reusable AI role.

Examples include:

- an operating review Agent
- a research Agent
- a finance reporting Agent
- a strategic planning Agent

The Agent can carry durable role instructions, context, approved Skills, and permitted Connections.

Its exact access remains controlled by the live workspace and Group permission model.

## Standardize recurring methods with Skills

A [Skill](/skills/index) is useful when leadership wants the same method applied repeatedly.

Examples could include:

- how to prepare a weekly company review
- how to summarize a strategic research topic
- how to review a proposed initiative
- how to prepare a decision brief
- how to create an executive handoff

The Skill stores the reusable method while the current task supplies the specific subject.

## Turn repeatable processes into Workflows

Use a [Workflow](/workflows/index) when a leadership process has several meaningful stages.

For example, a **Strategic Initiative Review** Workflow might include:

1. gather the current state
2. identify meaningful changes and risks
3. review unresolved decisions
4. prepare the leadership brief

Each step can use the live context, Skills, and Connections available during the run.

## Make handoffs easier

Leadership work often moves between founders, executives, operators, and functional teams.

Giga can keep durable context in the right place:

| Information                          | Best home                             |
| ------------------------------------ | ------------------------------------- |
| Stable background and constraints    | [Context Note](/tracks/context-notes) |
| Meaningful developments              | [Memory](/tracks/memory)              |
| Current position and decision record | Current Track State                   |
| Reports and authored output          | [Files](/tracks/files)                |
| Reusable task method                 | [Skill](/skills/index)                |
| Reusable process                     | [Workflow](/workflows/index)          |

This helps the next person pick up the work without rebuilding the context from scratch.
