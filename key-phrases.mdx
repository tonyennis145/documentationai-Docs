### Key Concept 1: Tracks

A track is a shared space for an exploration, a project, or an ongoing area of work. It gives Giga somewhere to keep what it learns, and lets you share it with the right people instead of the whole team. 

### Key Concept 2: Memory Materials

You don't **_have_** to know these concepts to use Giga, but it can sometimes help to get the most out of Giga. 

**Memories:** Memories are the smallest unit of recall within Giga. You never create them directly - Giga creates them when you ask it to capture something, like a conversation recap or meeting note summary. There are 8 different  types of memory: Decisions, Commitments, Ideas, Requests, Preferences, Facts, and Procedures. Memories are always attached to a Track - this is how we enable permission based sharing in Giga. For example, you might want certain memories to be available to your HR team, but not to everyone else. 

**Recaps:** Recaps are readable documents in Giga that get created when you ask Giga to capture either a Meeting Summary or a Chat Conversation Summary. 

**References:&#x20;**&#x52;eferences save links to important material that (usually) lives in external systems. You can think of them like bookmarks. 

# Key Phrases

These phrases are useful when using external Chat based AI tools. If you're using Giga's normal web based chat, Giga will handle this for you by default. 

## "Giga Link"

<Callout kind="info" collapsed="false">
  You can also just say "GL" for short
</Callout>

You usually use this at the **_beginning_** of a new chat thread, to link the thread to a Giga track. This will load in all of the context of that track, and also prompt you to save progress and context as the conversation progresses. When you say this, Giga will 

- Find the relevant track for the conversation, or ask you to specify or create one. 
- Load in the most recent activity and memory for the track, so that you can pick up where you left off. 
- Periodically remind you to save memories to the track

## "Giga Save"

<Callout kind="info" collapsed="false">
  You can also just say "GS" for short
</Callout>

Use this when you want Giga to capture whatever you just explored. Your agent will read the conversation, extract all the necessary memories and references,  save them to the right track, and create (or update) the relevant recap. 

That's it - that's all you need to use Giga's memory features
