**Activity & usage** is one place to see what Giga has been doing in your workspace and what it has cost. Open it from **Activity & usage** in the Giga web app.

| Section | What it shows | Who sees it |
| --- | --- | --- |
| **Usage** | Credits left, what used them this month, and spending for each of the last 30 days | Workspace owners |
| **Runs** | Your agent runs in this workspace, newest first | Everyone, for their own runs |
| **Credential activity** | Every time a credential was used | Everyone, for their own uses and credentials they own |
| **Credit history** | Every credit added to or spent in the workspace | Workspace owners |

## Usage and credits

Agent work and [Instant tools](/gateway/index) are paid from workspace credits. **Usage** shows the current balance, what used credits this month, and a day-by-day chart of the last 30 days. **Credit history** lists every top-up and every charge.

If credits run out, work that needs them stops, and Giga links you to top up.

## Runs

Every agent run you start is listed, newest first: chats, Workflows, Pulses and background jobs such as importing a meeting into memory. Open a run's chat to see what happened.

## Credential activity

Each time a credential from the [Vault](/connect/vault) is used, Giga records:

- **who** used it
- **which** credential
- **when**
- **what for**, such as the site or API it called, or a preview of the database query

You see your own uses, plus every use of credentials you own, including uses by people you've shared them with. Secrets, request headers and bodies are never recorded. The record is kept even if a credential is later deleted.
